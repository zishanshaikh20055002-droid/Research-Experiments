# Public release notes

Both authors authorized a public release of research code, derived prediction/results files, and the final PDF in this task. The package is staged locally. No Git remote, authenticated GitHub CLI, or verified public URL was available, so publication was not attempted and the manuscript has no repository link.

Excluded: raw XJTU-SY CSVs, the full derived processed feature matrix, virtual environments, caches, duplicate cloud bundles, unrelated production code, prior manuscript versions, and personal working files. The original dataset must be obtained separately from an authorized source. The unfinished Wiener Colab pilot and attempted lambda sweep are not represented as completed results; the lambda runner is retained only as code and explicitly marked unexecuted.

Historical run records, numerical CSVs, model checkpoints, plots, and prediction CSVs are release copies. Textual copies may replace user-specific absolute paths with `<PROJECT_ROOT>` or `<USER_HOME>`; original files remain unchanged. `MANIFEST.csv` hashes the released copies.

Before upload, the authors should choose a license for original code/results, verify third-party redistribution terms, inspect the staged file list, and create a public GitHub repository. A release URL should be added to the manuscript only after the public repository and its contents are independently reachable.
